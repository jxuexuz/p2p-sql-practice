## 可选：重新生成结果图

SQL项目运行不需要Python。仅重新排版已有结果时需要Python 3与Pillow，在项目根目录运行：

```sh
python tools/render_evidence.py
```

脚本读取已保存的JSON并生成PNG，不连接MySQL、不重新执行SQL；因此重新制图不等于重新验证数据库。默认使用Windows微软雅黑字体，其他环境可通过 `P2P_FONT_PATH` 指定可用的中文字体。

若修改SQL或数据，应重新执行相应测试并记录新结果，不应继续把旧证据视为新版本验证。
