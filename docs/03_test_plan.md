## 事务回滚实验

09有4个独立事务块，结果分别为：

1. 退货总量61超过原入库60：1行`OVER_RETURN`。
2. 付款20、核销21：1行`OVER_ALLOCATION`。
3. 供应商2的付款核销供应商1应付：`OVER_ALLOCATION`和`SUPPLIER_MISMATCH`共2行。
4. 应付剩20，再核销21：1行`NEGATIVE_AP`。

每块末尾ROLLBACK；最终异常0行，总余额390。若结果不符，先停止后续操作，记录SQL、错误和实际结果，不用删除数据来“凑”预期。

## 测试方法的局限

08的边界CTE验证比较表达式，不等于真实写表约束测试。09把异常记录实际插入事务中，验证业务异常视图能否发现，但不能证明系统会阻止异常提交。外键、唯一键及CHECK的拒绝测试由生成方在独立MySQL实例验证，见验证记录。

财务退款、税费、单据审批、权限、并发写入和数据变更审计均不在本版验收范围。
